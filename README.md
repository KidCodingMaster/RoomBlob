# RoomBlob
---

**Roomblob** is a software that can give people the best rooms in a hotel based on previous reviews

## Usage
---

Use the [create_rooms.py](create_rooms.py) file to add all the hotel rooms into the database. 
> [!CAUTION]
> This will override all previous reviews and previously added rooms in the database


Use the [give_review.py](give_review.py) file to give reviews about a room

Use the [suggest_room.py](suggest_room.py) file to suggest an unoccupied room based on previous review, and to occupy and vacate a room

## Installation

### PIP Packages:

1. **textblob**

### Commands:

```bash
pip install textblob
```
